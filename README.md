# Pentest Report Writer

Веб-приложение на Flask для написания отчётов о тестировании на проникновение.
Все отчёты собираются по одному шаблону: одинаковая структура, нумерация уязвимостей,
шкала критичности CVSS, титульный лист и оформление. Выгрузка в PDF и Word.

Приложение работает локально на вашем компьютере, данные никуда не отправляются.

---

## Возможности

- **Редактор как в текстовом процессоре:** заголовки, списки, таблицы, ссылки, блоки кода для
  HTTP-запросов, автосохранение, тёмная тема.
- **Уязвимости** с критичностью, оценкой CVSS, вектором, статусом и затронутыми ресурсами.
  В отчёте они автоматически сортируются по критичности и нумеруются F-01, F-02…
- **Калькулятор CVSS 3.1** с вопросами простым языком: балл, вектор и критичность считаются сами.
- **Библиотека уязвимостей:** 14 готовых шаблонов (SQLi, XSS, IDOR, SSRF, CSRF, TLS и др.) на
  русском и английском. Добавляются в отчёт одним кликом; свои описания можно сохранять в библиотеку.
- **Скриншоты:** вставка через ⌘V / Ctrl+V или перетаскиванием, подписи «Рисунок N — …»
  с автоматической нумерацией.
- **Рисование на скриншотах:** стрелки, рамки, карандаш, маркер, текст и **скрытие данных**
  (пикселизация паролей, токенов, ФИО).
- **Блоки-заготовки:** «Обратите внимание», «Внимание», «Критично», «Рекомендация».
- **Гриф отчёта:** строго конфиденциально, конфиденциально, для внутреннего использования,
  не конфиденциально, тестовый отчёт (с водяным знаком «ТЕСТ» в PDF).
- **Экспорт:** PDF (через печать браузера, A4 с колонтитулами и номерами страниц),
  Word (.docx), JSON для резервной копии и переноса на другой компьютер.
- Отчёты на русском или английском, дублирование отчётов.

## Установка

### Что нужно

- **Python 3.9 или новее.** Проверить версию:
  - macOS / Linux: `python3 --version`
  - Windows: `py --version`

  Если Python не установлен — скачайте его с [python.org](https://www.python.org/downloads/).
  На Windows при установке отметьте галочку **«Add python.exe to PATH»**.
- **Git** — чтобы скачать проект ([git-scm.com](https://git-scm.com/downloads)).
  Можно обойтись без него: на странице репозитория нажмите **Code → Download ZIP** и распакуйте архив.
- Браузер Chrome, Edge, Яндекс.Браузер или другой на Chromium — в нём PDF получается точнее всего.

### macOS / Linux

```bash
git clone git@github.com:errypie/report-writer.git
cd report-writer
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python app.py
```

### Windows (PowerShell или командная строка)

```bat
git clone git@github.com:errypie/report-writer.git
cd report-writer
py -m venv .venv
.venv\Scripts\pip install -r requirements.txt
.venv\Scripts\python app.py
```

> Если `git clone` по SSH выдаёт ошибку доступа, используйте HTTPS-адрес:
> `git clone https://github.com/errypie/report-writer.git`

После запуска откройте в браузере **http://127.0.0.1:8780**.

Чтобы остановить приложение — нажмите **Ctrl+C** в окне терминала.

## Повседневный запуск

Установка нужна один раз. Дальше достаточно зайти в папку и запустить:

```bash
cd report-writer
.venv/bin/python app.py          # macOS / Linux
.venv\Scripts\python app.py      # Windows
```

### Настройки при запуске

| Переменная | По умолчанию | Что делает |
|---|---|---|
| `PORT` | `8780` | Порт, на котором открывается приложение |
| `HOST` | `127.0.0.1` | Адрес. По умолчанию приложение доступно только с этого компьютера |
| `REPORTS_DEBUG` | выкл. | `1` — режим разработки с автоперезагрузкой при изменении кода |

Пример смены порта на 9000:

- macOS / Linux: `PORT=9000 .venv/bin/python app.py`
- Windows PowerShell: `$env:PORT=9000; .venv\Scripts\python app.py`
- Windows cmd: `set PORT=9000` и затем `.venv\Scripts\python app.py`

## Где хранятся данные

Всё хранится в папке проекта и сохраняется после закрытия приложения и перезагрузки компьютера:

| Что | Где |
|---|---|
| Отчёты, уязвимости, библиотека | `reports.db` (база SQLite) |
| Скриншоты | папка `uploads/` |
| Резервные копии базы | папка `backups/` — при каждом запуске и раз в сутки, хранятся последние 30 |

Эти файлы **не попадают в git** (см. `.gitignore`), потому что в отчётах реальные уязвимости.

**Перенос на другой компьютер:** скопируйте `reports.db` и папку `uploads/` в папку проекта
на новом компьютере. Либо откройте отчёт → **JSON**, а на новом компьютере на главной странице
нажмите **«Импорт JSON»** — скриншоты переносятся внутри файла.

**Восстановление из резервной копии:** остановите приложение, замените `reports.db` нужным
файлом из `backups/` (переименовав его в `reports.db`) и запустите снова.

## Обновление

```bash
cd report-writer
git pull
.venv/bin/pip install -r requirements.txt      # Windows: .venv\Scripts\pip install -r requirements.txt
```

Ваши отчёты при обновлении не затрагиваются. Изменения структуры базы применяются автоматически
при запуске.

## Как пользоваться

1. На главной нажмите **«Новый отчёт (RU)»** — отчёт создаётся уже со стандартной структурой.
2. Заполните сведения о документе: заказчик, объект, даты, исполнители, гриф.
3. Добавьте уязвимости: **«Из библиотеки»** (готовое описание) или **«+ Добавить»** (с нуля).
   Оценку задайте через **«Калькулятор»** рядом с полем CVSS.
4. Вставляйте скриншоты (⌘V / Ctrl+V). Наведите мышку на скриншот → **«Рисовать»**, чтобы
   выделить важное или скрыть пароли.
5. **«Отчёт / PDF»** → «Печать / сохранить PDF», или кнопка **«Word»**.

Горячие клавиши: ⌘S / Ctrl+S — сохранить, ⌘K / Ctrl+K — ссылка, ⌘B / ⌘I / ⌘U — форматирование.

**Совет по PDF:** в окне печати выберите «Сохранить как PDF», включите «Фоновые изображения»
и отключите «Верхние и нижние колонтитулы» браузера — у отчёта свои колонтитулы.

## Настройка оформления

| Что изменить | Где |
|---|---|
| Логотип | `static/img/logo.svg` (сайт и PDF) и `static/img/logo.png` (Word) — сейчас это заглушки, замените на официальные файлы из брендбука, сохранив имена |

| Цвета | начало файлов `static/css/app.css` и `static/css/report.css` |

| Встроенные шаблоны уязвимостей | `library_seed.py` (добавляются при первом запуске) |

## Безопасность

- Приложение рассчитано на работу на одном компьютере: нет входа по паролю и разграничения прав.
  Не открывайте его в сеть (`HOST=0.0.0.0`) без дополнительной защиты.
- Весь HTML из редактора очищается на сервере (библиотека nh3), загружаются только изображения
  PNG, JPEG, GIF и WebP до 15 МБ.
- Оригиналы скриншотов, которые больше не используются (например, до скрытия пароля),
  удаляются с диска через сутки.

```

report_texts.py     фиксированные тексты шаблона отчёта (RU / EN)
library_seed.py     встроенные шаблоны уязвимостей
cvss.py             расчёт CVSS 3.1 (такой же, как в static/js/cvss.js)
docx_export.py      сборка отчёта в Word
templates/          страницы: главная, редактор, отчёт, библиотека
static/css, js, img стили, скрипты редактора, логотип
```
